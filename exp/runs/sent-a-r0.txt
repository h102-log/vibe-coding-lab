- 완료했다고 판단하면 종료하라. 정해진 보고 형식은 없다.

# Todo 앱 — 구현 계약

이 문서와 `tests/ac/todo.ac.test.tsx`가 요구사항의 전부다. 다른 곳을 참조하지 마라.
**이 문서와 인수 테스트가 어긋나면 인수 테스트가 이긴다.**

## 만들 것

로컬에서 도는 단일 페이지 Todo 앱.

## 고정된 것 (바꾸지 마라)

- **스택**: Vite + React + TypeScript. 이미 설치되어 있다. 다른 프레임워크로 갈아타지 마라.
- **구현 진입점**: `src/App.tsx`의 default export 컴포넌트.
  - 그 아래의 파일 분할, 상태 관리 방식은 **전부 재량**이다. 규정하지 않는다.
- **`tests/ac/**`** — 인수 테스트와 그 실행 설정. 읽어도 되지만 **수정·삭제·이동 금지**.
- **`package.json`의 `build`·`test:ac` 스크립트**, **`tsconfig.app.json`의 `"strict": true`**.

## DOM 계약 (data-testid)

인수 테스트는 아래 `data-testid`로만 화면을 찾는다. 마크업 구조·클래스명·태그는 자유지만 이 속성은 반드시 있어야 한다.

| testid | 무엇 | 조건 |
|---|---|---|
| `todo-input` | 새 항목 입력창 | Enter로 제출. 비어있지 않은 accessible name 필요 |
| `todo-item` | 항목 하나 (0..n개) | **화면에 실제로 보이는 것만.** 필터로 감춘 항목은 렌더하지 마라 |
| `todo-title` | 항목 제목 텍스트 | `todo-item` 안에 정확히 1개 |
| `todo-toggle` | 완료 체크박스 | `input[type="checkbox"]`여야 한다. accessible name 필요. **접근성 트리에서 감추지 마라** (`display:none`·`aria-hidden` 금지) |
| `todo-delete` | 항목 삭제 버튼 | `<button>`이어야 한다. accessible name 필요 |
| `todo-count` | 미완료 개수 표시 | 문구는 자유(`3개 남음` / `3 items left`). 단 **텍스트에 숫자는 정확히 하나만** 넣어라 |
| `filter-all` | 전체 필터 버튼 | |
| `filter-active` | 미완료 필터 버튼 | |
| `filter-completed` | 완료 필터 버튼 | |

## 동작 요구사항

1. **추가** — 입력창에 텍스트를 넣고 Enter → 항목 1개 생성, 제목이 입력값과 정확히 일치, 입력창이 비워진다.
2. **공백 거부** — 빈 문자열이나 공백만 제출하면 아무것도 추가되지 않는다.
3. **완료 토글** — 체크박스로 완료 ↔ 미완료를 왕복할 수 있다.
4. **삭제** — 누른 항목만 사라지고 나머지는 원래 순서를 유지한다.
5. **미완료 개수** — 추가·토글·삭제에 따라 갱신된다.
6. **필터** — 전체 / 미완료 / 완료가 각각 올바른 부분집합만 보여준다.
7. **영속성** — `localStorage`에 저장하고, 다시 열었을 때 항목과 완료 상태가 그대로 남는다. 저장 키 이름은 자유.
8. **접근성** — 입력창·토글·삭제 버튼이 각각 비어있지 않은 accessible name을 가진다 (`aria-label` 등).
9. **타입체크·빌드** — `strict` 모드에서 타입 오류 0, 빌드 성공.
10. **표시 순서** — 항목은 항상 **추가된 순서대로** 표시한다. 새 항목은 목록 맨 끝에 붙는다. 완료했다고 아래로 옮기거나 재정렬하지 마라.

## 범위 밖 (만들지 마라)

로그인·계정, 서버 API·DB, 배포, 인라인 제목 편집(더블클릭 수정), 드래그 정렬,
전체 완료 토글·완료 일괄 삭제, 마감일·우선순위·태그·검색, 다크모드·테마 전환,
애니메이션, 다국어(한국어 단일 로케일), SEO 메타태그.

**CSS·스타일 작업** — `src/App.css`·`src/index.css`를 수정하지 말고 새 스타일 파일도 만들지 마라. 화면 모양은 평가 항목이 아니다.

npm run dev       # 개발 서버
