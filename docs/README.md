실험 설계에 관한 결정은 여기 없다 — 실험 1은 `exp/FROZEN.md`, 2는 `exp2/FROZEN2.md`, 3은 `exp3/FROZEN3.md`가 SSOT다. `docs/`는 그 결정에 이르는 과정과 근거를 담고, 결과는 `REPORT.md`(SDD) · `REPORT2.md`(검증 자산 영속성) · `REPORT3.md`(자산 회수)에 있다.
