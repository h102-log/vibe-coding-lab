# thoughts/

여기는 완성된 문서가 아니라 **다듬지 않은 생각을 남기는 곳**이다. 리서치 보고서나 스펙 문서와 다르게, 결론이 안 나도 되고 주저리주저리 써도 된다. 나중에 "그때 내가 무슨 생각으로 이 결정을 했었지"를 확인하기 위한 기록.

## 파일 이름 규칙

`YYYY-MM-DD-짧은-주제.md` (kebab-case, 한글 가능). 같은 날 여러 개면 주제로 구분한다.

## 무엇을 적나

- 프로젝트 방향에 대한 고민, 갈아엎을지 말지 같은 판단
- 어떤 결정을 왜 내렸는지, 그 순간의 맥락
- Claude와 나눈 설계 대화 — 결론이 났든 안 났든

## 스킬

이 폴더에 대화 내용을 정리해 남기고 싶으면 `thought-dump` 스킬을 쓴다 ("생각 정리해줘", "대화 내용 문서로 남겨줘" 같은 말로 트리거됨). 정의는 `.claude/skills/thought-dump/SKILL.md`.
