allowed-tools: Read, Write, Edit, Glob, Grep, Bash(node:*)
---

**$ARGUMENTS 가 `delta` 로 시작하면** — 기존 코드 수정 루프다. 본 `SPEC.md`는 직접 고치지 않는다.

1. `SPEC.delta.md`가 **이미 있으면 새로 만들지 마라** — `verify`를 돌려 상태를 보고하고, 같은
   작업 단위면 기존 델타에 항목을 더한다. 다른 작업이면 기존 사이클 종결(대조를 채우고 완료)을
   먼저 제안한다. 방치 델타의 폐기는 사용자 몫이니 임의로 지우지 마라.
2. 없으면 `delta-template.md` 사본으로 만들고 한 줄 요구를 ADDED/MODIFIED/REMOVED로 쪼갠다.
   MODIFIED 대상 `` `파일:심볼` ``은 구현을 시작하기 **전에** 채운다. ID는 본 SPEC의 S/I/U 최대
   번호에 이어 쓰고, 미확정 항목(U)은 불릿이 아니라 6열 표 행으로 적는다.
3. `node "${CLAUDE_PLUGIN_ROOT}/spec-delta.mjs" verify SPEC.delta.md` 로 확인한 뒤 구현한다.
   구현이 끝나면 `## 대조` 표를 채운다 — 완료 선언 시 게이트가 D1~D5를 보고, **전건 통과하면
   그 자리에서 `SPEC.md`에 병합하고 델타를 지운다**(사람이 `merge`를 칠 필요가 없다).

그 외에는 프로젝트 루트의 `SPEC.md` 상태에 따라 갈라진다.

**없으면** — sdd 스킬(`skills/sdd/SKILL.md`)의 절차대로 새로 쓴다. §2 점검표 10범주와
미확정 6열 표를 빠뜨리지 마라. 이 둘이 없으면 게이트가 구현 단계에서 막는다.

§0~§2 초안까지 쓴 뒤, 구현 문장을 쓰기 전에 **침묵 인터뷰**를 한 번 한다.

1. `node "${CLAUDE_PLUGIN_ROOT}/spec-interview.mjs" stats` 를 먼저 돌린다. `mute 권장` 범주가
   있으면 질문 전에 보고하고 이번 세션에서 그 범주의 승격을 멈출지 사용자에게 묻는다 — 권장이지
   결정이 아니고, 저장하지 않는다.
2. §2 점검표의 `Partial`/`Missing` 중 SKILL.md §2 선별 기준대로 **최대 3개만** 질문으로 승격한다.
3. **한 번에 하나씩** 묻는다. 각 질문은 네 줄이다 — 질문 한 줄 · `왜 모호한가` 한 줄(요구 문장의
   무엇이 그 값을 정하지 않았는가) · `제안 기본값` 하나 · `답을 쓰거나 / Enter(기본값 수락) /
   «건너뜀»` 안내. 앞 답을 보고 다음 질문을 다듬어도 된다.
4. 응답마다 두 가지를 한다.
   - **SPEC 반영** — 답변이면 §1에 S문장(근거: 사용자, 날짜)으로 올린다 / Enter면 §2.2에 I문장
     `[추론]`을 붙여 남기고 §2.3 그 행의 상태를 `위임`(날짜)로 적는다(Enter는 위임이지 선택이
     아니다 — SKILL.md:63) / 건너뜀이면 문장을 만들지 말고 §2.3 행 상태를 `선택 대기`로 둔다.
   - **기록** — `node "${CLAUDE_PLUGIN_ROOT}/spec-interview.mjs" log --cat <1..10> --resp
     <answer|accept|skip> --q "<질문>" [--u <U행>]`. 실패해도 인터뷰는 계속한다.
5. 승격되지 않은 후보는 화면에 출력하지 말고 §2.3 표에만 적는다. 사용자가 «그만 물어»라고 하면
   남은 질문은 묻지도 기록하지도 않는다.
6. 인터뷰는 **한 번만** 한다 — 재실행하거나 추가 질문 라운드를 만들지 마라.

**있으면** — 먼저 검사기를 돌리고, 그 출력을 근거로 보고한다:

```
node "${CLAUDE_PLUGIN_ROOT}/spec-verify.mjs" SPEC.md
```

- 위반 C1~C3 → SPEC 자체가 미완이다. 해당 절을 채운다.
- 위반 C4 → 지목되지 않은 문장이 있다. 구현 위치(파일:줄)를 찾아 §3에 적거나, 기각 사유를 적는다.
- 위반 C5 → `선택 대기` 항목이 재확인 목록에 빠졌다. 사용자에게 제시할 목록에 넣는다.
- 경고 → 위반이 아니다. 사람이 판단할 몫이니 보고만 하고 임의로 고치지 마라.

$ARGUMENTS 가 경로면 그 경로를 `SPEC.md` 대신 쓴다.
