## 1. 명시된 것

요청 문장에서 직접 읽어낼 수 있는 요구다. 각 문장 끝 괄호가 근거 위치다.

- S1. CartList가 렌더되면 담은 항목마다 하나씩, 항목 목록의 줄이 렌더된다. (근거: 요청 1)
- S2. 각 줄에는 그 항목의 이름, 단가, 수량, 그리고 수량 × 단가로 계산된 소계가 렌더된다. (근거: 요청 1)
- S3. 각 줄에는 감소 버튼(−)과 증가 버튼(+) 두 개로 이루어진 수량 스테퍼가 렌더된다. (근거: 요청 2)
- S4. 두 스테퍼 버튼은 아이콘만 렌더한다 — 버튼의 자식은 `aria-hidden` 아이콘 요소뿐이고 버튼의 표시 텍스트는 비어 있다. (근거: 요청 2 «아이콘만 있는 작은 버튼»)
- S5. 어떤 줄의 + 버튼을 1회 누르면 그 줄의 수량이 직전보다 정확히 1 큰 값으로 렌더되고, 그 줄의 소계도 새 수량 × 단가로 갱신되어 렌더된다. (근거: 요청 3)
- S6. 수량이 2 이상인 줄의 − 버튼을 1회 누르면 그 줄의 수량이 직전보다 정확히 1 작은 값으로 렌더되고, 소계도 새 수량 × 단가로 갱신되어 렌더된다. (근거: 요청 3)
- S7. 목록 아래에 전체 합계가 렌더된다. (근거: 요청 5)
- S8. CartList는 필수 props 없이 렌더 가능하며, 시작 항목 2~3개가 컴포넌트 모듈 안에 하드코딩되어 있다. (근거: 요청 6)
- S9. `src/App.tsx`의 App이 렌더되면 CartList가 렌더된다. (근거: 요청 «src/App.tsx 가 그것을 렌더하게 한다»)
- S10. `npm run build`(tsc 타입체크 + vite 빌드)가 종료 코드 0으로 끝난다. (근거: 요청 «완료 조건»)
- S11. 어떤 줄의 수량이 0이 되면 그 줄은 즉시 언렌더되고, 그 이후 전체 합계에 기여하지 않는다. (근거: 사용자 확정 2026-08-25 — U1 안 A)
- S12. 수량이 1인 줄의 − 버튼을 1회 누르면 그 줄의 수량은 0이 되고, 그 결과 S11에 따라 그 줄이 언렌더된다. (근거: 사용자 확정 2026-08-25 — U2 기본값)
- S13. 각 스테퍼 버튼의 아이콘은 `aria-hidden="true"` 속성을 가진 인라인 `<svg>` 요소 하나로 렌더된다. (근거: 사용자 확정 2026-08-25 — U3 기본값)

## 2. 명시되지 않은 것

요청이 침묵하는 지점이다. 확정한 것은 검증 가능한 문장으로 적고 `[추론]`을 달았다.

### 2.1 확정한 추론 문장

- I1. 각 스테퍼 버튼은 항목 이름을 포함한 접근 가능한 이름을 가진다 — 감소 버튼은 `«{이름}» 수량 감소`, 증가 버튼은 `«{이름}» 수량 증가` — 이므로 같은 화면의 서로 다른 줄의 버튼이 이름으로 구별된다. [추론]
- I2. 두 스테퍼 버튼은 `<button type="button">`으로 렌더되어 Tab 키 순서에 들어가고(도달 가능) 키보드 활성화가 가능하다. [추론]
- I3. 수량은 0 미만이 되지 않는다 — 수량을 0 미만으로 만드는 조작 경로가 존재하지 않는다. [추론]
- I4. 전체 합계는 그 시점에 담겨 있는 항목들의 소계 합과 같다 — 담긴 것이 아닌 항목은 합계에 기여하지 않는다. [추론]
- I5. 담긴 항목이 하나도 없으면 항목 줄이 하나도 렌더되지 않고, 대신 빈 상태 텍스트 «담은 항목이 없습니다»가 렌더되며, 합계는 0원으로 렌더된다. [추론]
- I6. 금액(단가·소계·합계)은 0 이상 정수 원 단위이며 천 단위 쉼표와 «원» 접미가 붙은 형식으로 렌더된다 (예: `12,000원`). [추론]
- I7. 담은 항목 상태는 CartList 내부의 `useState`가 소유한다 — 상위에서 상태를 주입하지 않아도 스테퍼 조작이 화면에 반영된다. [추론]
- I8. 항목 목록은 `<ul>`/`<li>`로 렌더되고 각 줄의 React key는 항목의 고유 id다(이름이나 배열 인덱스가 아니다). [추론]
- I9. 합계 줄에는 «합계» 레이블 텍스트와 금액이 함께 렌더된다. [추론]
- I10. CartList는 네트워크·브라우저 저장소·타이머에 의존하지 않는다 — 렌더 시점의 초기 상태는 항상 하드코딩된 시작 데이터다. [추론]
- I11. 스테퍼 조작은 조작한 줄에만 영향을 준다 — 한 줄의 +/− 를 눌러도 다른 줄의 수량과 소계는 그대로 렌더된다. [추론]
- I12. 하드코딩 시작 데이터는 정확히 3개 항목이다 — `에스프레소 원두 200g` 12000원 2개, `드리퍼` 18500원 1개, `종이 필터 100매` 4500원 3개 — 이므로 초기 합계는 56000원이다. [추론]
- I13. 각 줄의 단가·수량·소계는 각각 `data-testid="unit-price"` · `data-testid="qty"` · `data-testid="subtotal"` 요소에, 전체 합계는 `data-testid="cart-total"` 요소에 렌더된다. [추론]
