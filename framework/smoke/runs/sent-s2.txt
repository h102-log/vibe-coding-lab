React 컴포넌트를 구현하라. 프로젝트는 준비돼 있다 (React 19·vite·typescript·vitest·jsdom·Testing Library 설치됨, npm run build = tsc 타입체크 + vite 빌드).

src/TagInput.tsx 에 태그 입력 컴포넌트 TagInput을 구현하고, src/App.tsx 가 그것을 렌더하게 한다:

1. 텍스트 입력창 1개와 추가된 태그 목록을 렌더한다.
2. 입력창에서 Enter를 누르면 입력값이 태그로 추가되고 입력창은 비워진다.
   태그는 앞뒤 공백을 제거해 저장하고, 공백 제거 후 빈 문자열이면 추가하지 않는다.
3. 이미 있는 태그와 같은 값이면(공백 제거 후 비교) 다시 추가하지 않는다.
4. 각 태그 옆에 제거 버튼이 있고, 누르면 그 태그만 목록에서 사라진다(숨김이 아니라 언렌더).
5. 태그가 0개일 때는 목록 대신 "태그 없음" 텍스트를 렌더한다.

완료 조건: npm run build 가 종료 코드 0으로 끝난다.
