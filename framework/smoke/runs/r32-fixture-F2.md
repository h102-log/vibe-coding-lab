# 최종 응답

구현 끝. `npm run build`는 0으로 종료한다. `SPEC.md`를 먼저 쓴 뒤 §3에서 문장마다 코드 위치를 짚었다.

**만든 것** — `src/CartList.tsx` · `src/CartList.css` · `src/App.tsx` · `SPEC.md`.

**M3** — 빈 목록일 때 합계 줄을 어떻게 할지 (a)/(b) 중 하나를 골라 달라:

- **(a) 합계 줄도 함께 사라지고 «담은 항목이 없어요»만 남는다 — 현재 기본값(권장)**
- (b) `전체 합계 ₩0`을 계속 표시한다

M6·M8은 지금은 묻지 않는다 — 기록만 해뒀다.

**확정이 필요한 것** — `SPEC.md` §2-3에 침묵 지점 9개를 기본값·대안·번복 조건과 함께 적었고, 사용자가 답한 M1을 뺀 나머지는 모두 `선택 대기` 상태로 두고 진행했다. 그중 답이 오면 구현이 달라지는 둘:

1. **빈 목록일 때 합계 줄** — 지금은 합계 줄이 목록과 함께 사라진다. 대안은 `₩0`을 계속 두는 것.
2. **줄이 제거될 때 포커스** — 지금은 이웃 줄의 − 버튼으로 옮긴다. 요청에 없는 동작이라 빼도 되지만, 빼면 − 를 연달아 누르던 키보드 사용자의 포커스가 문서 최상위로 튄다.

둘 중 어느 쪽이든 지금 기본값과 다르게 가고 싶다면 알려 달라 — 표의 행과 코드를 같이 고치겠다.

임시 vitest 테스트는 확인 후 삭제했다 — 정식 테스트로 남기길 바란다면 `vite.config.ts`에 test 설정을 추가하고 다시 넣겠다.
