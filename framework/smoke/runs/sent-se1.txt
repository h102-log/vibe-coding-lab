React 컴포넌트를 구현하라. 프로젝트는 준비돼 있다 (React 19·vite·typescript·vitest·jsdom·Testing Library 설치됨, npm run build = tsc 타입체크 + vite 빌드).

src/CartList.tsx 에 담은 항목 목록 컴포넌트 CartList를 구현하고, src/App.tsx 가 그것을 렌더하게 한다:

1. 담은 항목들을 목록으로 렌더한다. 각 줄에 항목 이름, 단가, 수량, 수량 × 단가 소계를 보여준다.
2. 각 줄에 수량 스테퍼가 있다 — 아이콘만 있는 작은 버튼 두 개(−, +)다.
3. + 를 누르면 그 줄의 수량이 1 오르고, − 를 누르면 1 내려간다.
4. 수량이 0이 되면 그 줄은 더 이상 담긴 것이 아니다.
5. 목록 아래에 전체 합계를 보여준다.
6. 시작 데이터는 컴포넌트 안에 두세 개 하드코딩해도 된다.

완료 조건: npm run build 가 종료 코드 0으로 끝난다.
