## 0. 스펙 소스

스펙·계약 문서가 없다(`README.md`는 Vite 안내문). 요청 문장이 근거이고, §2 항목은 기본값으로 확정하되 상태를 `선택 대기`로 남긴다.

## 1. 명시된 것

1. `src/CartList.tsx`가 `CartList`를 export한다. [요청 본문]
2. `src/App.tsx`가 `CartList`를 렌더한다. [요청 본문]
3. 담긴 항목마다 한 줄이 렌더되고, 각 줄은 이름·단가·수량·소계 네 값을 표시한다. 소계 = 수량 × 단가. [요청 1]
4. 각 줄에 아이콘만 있는 작은 버튼 두 개(−, +)가 있다. [요청 2]
5. + 는 그 줄의 수량만 1 올리고, − 는 그 줄의 수량만 1 내린다. [요청 3]
6. 수량이 0인 줄은 담긴 항목이 아니다 — 전체 합계에 기여하지 않는다. [요청 4]
7. 목록 아래에 전체 합계가 표시된다. [요청 5]
8. 시작 데이터(연필·지우개·노트)는 컴포넌트 안에 하드코딩한다. [요청 6]
9. `npm run build`가 종료 코드 0으로 끝난다. [완료 조건]

4번 보충 — 두 버튼은 아이콘만이라 접근 가능한 이름(스크린 리더용)을 붙였다.

### 2-2. 추론으로 확정한 문장

- 항목 한 개는 `id`·`name`·`unitPrice`·`quantity`를 가지며 `id`가 React `key`다. [추론]
- 상태는 컴포넌트 안 `useState`에 두고 바깥에서 주입받지 않는다. [추론]
- 수량 하한은 0이고 음수가 되지 않는다. [추론]
- 수량 1에서 − 를 누르면 0이 되고 그 줄은 목록에서 빠진다(N1 기본값). [추론]
- 담긴 줄이 0개면 «장바구니가 비었습니다»를 보이고 합계는 `0원`으로 유지한다. [추론]
- 금액은 정수 원 단위이고 `원` 접미를 붙인다(`2,400원`). [추론]
- 스타일은 `src/CartList.css` 한 파일에 두고 기존 CSS는 손대지 않는다. [추론]
