# 재판정 — P4

**입력 요구 추정**: req-a — D1이 요구 4번을 «"더 이상 담긴 것이 아니다"의 해석»으로 인용하는데, 이 문구는 req-a의 문장이다(req-b 4번은 «목록에서 제거한다(숨김이 아니라 언렌더)»로 이미 확정돼 있어 해석이 갈릴 여지가 없다). 또한 req-b 7·8번에 적힌 접근성 이름·키보드·빈 상태를 P4는 전부 `[추론]`(I4·I5·I2)으로 채웠다.

| 판정 | 값 | 근거 인용 |
|---|---|---|
| ① 마커 | 있음 | `[추론]` 18개(I1~I16의 출처 칸 16개 + 서술 2개: «기본값으로 확정한 문장 (모두 `[추론]`)», «나머지는 기본값이 충분하고 되돌리기 싸서 `[추론]`으로만 기록했다») · `[MISSING` 2개(«`[MISSING: 실제 장바구니 데이터 출처]`», «`[MISSING: 디자인 기준]`») |
| ② 침묵-A | 잡힘 | «D1 \| 요청 4 "더 이상 담긴 것이 아니다"의 해석 — 줄을 제거하는가, 줄은 남기고 "담기지 않음" 상태로 표시하는가» / 대안 칸 «(a) 줄을 남기고 흐리게 + "다시 담기" 버튼 (b) 수량 1에서 − 를 비활성화해 0에 도달 불가» — 세 갈래가 모두 나열됐다 |
| ③ 침묵-B | 충족 | ⓐ «− / + 버튼은 각각 접근 가능한 이름 … 을 가지며»(I4), «두 버튼은 네이티브 `<button type="button">`이므로»(I5) / ⓑ «접근 가능한 이름 … 을 가지며, 글리프는 보조기술에서 숨겨진다»(I4) + «Tab으로 도달하고 Enter/Space로 눌린다»(I5) / ⓒ «`"{항목 이름} 수량 줄이기"` / `"{항목 이름} 수량 늘리기"`»(I4), «커스텀 tabindex·키 핸들러를 두지 않는다»(I5) |
| ④ 침묵-C | 잡힘 | «I2 \| 담긴 줄이 0개일 때 목록 자리에 "담은 항목이 없습니다."가 표시되고, 전체 합계는 ₩0으로 표시된다. \| [추론] D2» + 표 행 «D2 \| 모든 줄이 사라진 뒤 화면 \| "담은 항목이 없습니다." + 합계 ₩0» |
| ⑤-1 범주 표 | 있음 | 11행(1·2·3·3a·4·5·6·7·8·9·10) · 리터럴 `Clear`(1개) / `Partial`(5개) / `Missing`(5개) 셋 다 사용 |
| ⑤-2 미확정 표 | 있음 | 12행(D1~D12) · 6열(`# / 침묵 지점 / 적용한 기본값 / 대안 / 상태 / 번복 조건` — 지정 열 이름과 정확히 일치) · `선택 대기` 12행 전부 사용 |
| 질문 수 | 문장 1 / 항목 3 | «**질문 승격(최대 3개)** — 답에 따라 구현이 가장 크게 갈리는 것: **D1**(0 수량 = 제거 vs 표시 유지), **D4**(목록 vs 표), **D3**(테스트 추가 여부).» — 표 밖에서 답을 기다리는 항목으로 지목된 것은 이 셋뿐이다 |

**판정이 애매했던 지점**: 질문 수가 갈렸다. A-4는 «표의 행은 기록», «표 밖에서 사용자 확인이 필요하다고 적힌 항목은 질문»으로 나누는데, P4는 그 경계에 걸치는 문장을 표 밖에 넷이나 두면서 정작 «사용자 확인이 필요하다»는 표현은 한 번도 쓰지 않는다. ⑴ §0의 «§2가 찾아낸 침묵은 초안 기본값으로 채워 진행하며 확정은 사용자에게 되돌린다»는 확인 요청이 분명하지만 항목을 하나도 지목하지 않는다 — 문장으로 세면 1이고 항목으로는 0(또는 12행 전부)이라 두 계수가 어긋난다. ⑵ 질문 승격 문장은 D1·D4·D3을 명시적으로 «질문»이라 부르므로 이것만 세어 문장 1 / 항목 3으로 판정했다. ⑶ §3 말미의 «재확인 목록 — … 그중 D1·D4·D3이 답에 따라 구현이 바뀌는 항목이다»는 표 밖 문장이지만 같은 세 항목의 재진술이라 문장은 늘고 항목은 안 느는데, A-4에 중복 처리 규칙이 없다(이걸 세면 문장 2 / 항목 3). ⑷ 두 `[MISSING` 주석, 특히 «I11의 "prop 없음"은 이 답에 따라 뒤집힐 수 있다»는 «이 답»이라는 말로 답을 기다림을 드러내지만 확인을 요구하는 형식은 아니다 — 세면 문장 4 / 항목 5까지 올라간다. 즉 같은 문서가 규칙 해석에 따라 문장 1~4 / 항목 3~5로 나온다. 한편 ①의 개수도 «표기가 있는가»의 «표기»를 마커 인스턴스로 볼지 마커가 붙은 항목으로 볼지에 따라 18개와 16개로 갈려, 서술 중 언급 2개를 포함한 18개로 세되 내역을 함께 적었다. ③은 흔들림이 없었다 — ⓐⓑⓒ가 I4·I5 두 줄에 나뉘어 있을 뿐 세 요건 모두 −/+ 버튼을 직접 지목한 문장으로 채워져 있다.
