**판정이 애매했던 지점**: 네 곳에서 갈렸다. ⑴ ⑤-2의 «행 수»가 A-3의 주값 규정(«`선택 대기`가 적힌 표 행 수»=9)인지 A-5 형식란의 «행 수»(물리 10)인지 서식이 이중이라, 값 칸은 규정대로 9행으로 적고 물리 10을 근거란에 병기했다. ⑵ §2-4 직후 «다른 행은 `[추론]` 기본값으로 두고 묻지 않는다»는 K1·K2·K7 외 행을 명시적으로 «묻지 않는다»고 내리는 문장이지만, A-4 «충돌»의 강등은 **최종 응답이 SPEC의 (ii)/(iii) 지목 항목을** 내리는 경우로 한정돼 있고 여기서는 SPEC 내부·비지목 행이 대상이라 강등에 넣지 않았다 — 강등 규정이 문서 내부 자기강등을 다루지 않는 구멍이다. ⑶ 응답이 K1만 (a)/(b)/(c)로 펼치고 K2·K7은 «사용자 확정이 필요하다»까지만 반복하는데, 이를 사실상의 격하로 볼지 판단이 필요했다 — «지금은 묻지 않는다/기록만 해뒀다» 류 명시 어구가 없고 오히려 확정 필요를 재확인하므로 강등 0으로 두었다. ⑷ §3 «재확인 목록»은 A-4 (ii)가 명시로 인정하는 라벨이지만 라벨이 직접 이끄는 첫 문장이 전수 포인터라 (b)가 먼저 걸리고, 뒤 문장은 열거가 아닌 서술문이라 라벨이 미치지 않아 결국 SPEC 쪽 «재확인 목록» 블록 전체가 0문장이 됐다 — 같은 세 항목이 응답에서야 (ii)로 잡히는 비대칭이 남는다.
