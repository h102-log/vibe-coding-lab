### 항목으로 만들지 않은 기준

- "작은 버튼" — jsdom에는 레이아웃이 없다. 크기는 재지 못하고 대체 관측도 없다(EV4는 «아이콘만»까지만 잰다).
- "npm run build 가 종료 코드 0" — 러너 판정은 가능하나 eval-run 타임아웃(120s) 안에서 빌드를 돌리는 것은
  계측 실패로 새기 쉽다. 항목에서 빼고 완료 직전에 직접 실행해 종료 코드를 보고한다.
- "시작 데이터는 ... 하드코딩해도 된다" — 허용이지 요구가 아니다. 줄 수 2~3만 EV1이 부수적으로 잰다.
