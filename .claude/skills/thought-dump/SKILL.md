# thought-dump

`docs/thoughts/`는 완성된 문서가 아니라 다듬지 않은 생각을 남기는 폴더다 (`docs/thoughts/README.md` 참고). 이 스킬은 지금까지의 대화를 그 폴더에 새 파일로 정리한다.

## 범위 정하기

- 사용자가 범위를 지정했으면 (예: "방금 그 얘기만", "오늘 나눈 거 전부") 그대로 따른다.
- 지정 안 했으면 직전에 다룬 주제 하나를 기본 범위로 잡는다 — 세션 전체를 억지로 욱여넣지 않는다. 애매하면 뭘 남길지 한 줄로 물어본다.

## 파일 작성

- 경로: `docs/thoughts/YYYY-MM-DD-짧은-주제.md` (kebab-case, 한글 가능). 오늘 날짜로 이미 관련 파일이 있으면 이어 쓸지 새로 쓸지 판단 — 같은 주제 연장이면 그 파일에 이어 붙이고, 새 주제면 새 파일.
- 톤: 구어체, 정리보고서처럼 딱딱하게 쓰지 않는다. 실제 오간 말(사용자 발언은 가능하면 인용)과 흐름을 따라간다.
- 결론이 안 났으면 안 났다고 그대로 적는다. 억지로 결론을 만들어내지 않는다.
- 이미 다른 문서(리서치 보고서, 이전 thoughts 파일, 메모리)에 있는 내용은 요약 + 링크로 참조하고 그대로 베끼지 않는다.
- 구성은 자유이되, 이 순서가 보통 잘 맞는다: 어쩌다 이 얘기가 나왔나 → 오간 논의 → 결정된 것 / 아직 안 정해진 것 → 다음에 할 일.

## 완료 후

작성한 파일 경로를 사용자에게 알려준다. `docs/thoughts/README.md`나 파일 목록을 따로 갱신할 필요는 없다 — 폴더 자체가 목록이다.
